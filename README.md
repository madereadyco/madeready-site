# Made Ready

Website for Made Ready: demo-first website redesigns and monthly care plans for small UK trades. Plain HTML and CSS, no build step, no JavaScript.

## Files
- `index.html` – home page
- `privacy.html` – privacy notice (DRAFT STUB, must be completed)
- `styles.css` – all styles
- `docs/` – backup of the previous site copy

## Before going live
Search for `[PHONE]`, `[EMAIL]`, `[£ TBC]`, `[PHOTO]` and `PHONE_NUMBER_HERE` / `EMAIL_ADDRESS_HERE` (link targets) and replace them. Complete `privacy.html`.

## Deploy
Merging to `main` auto-deploys to Vercel. Use PR preview links to review.
