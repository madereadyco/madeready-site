Pell & Wren: style options

Internal mockup, not linked from the live site. Four directions for the “after” concept. Ratios are WCAG contrast (4.5:1 needed for normal text). None use navy or copper. Option 1 is the current build (still cream, but oxblood and brass); Options 2 to 4 are all clearly away from madeready.co.

Recommendation: Option 2, Modern clean. Strong contrast on every pair, and it looks like a firm you’d trust with a bathroom install, which is where the margin is. Option 3 is the pick if the target is emergency call-outs, and Option 1 is the safest if you want to keep what’s built. Still, the real test is which one looks right next to a prospect’s own “before” site.

1. Heritage (current)

Established, trustworthy, a bit old-school. The letterhead look.

Palette: Oxblood, brass

Fonts: Georgia headlines + Trebuchet body

Buttons: Square-ish, caps, letter-spaced

Cards: 1px rule, thick red top edge
