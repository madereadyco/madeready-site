Pell & Wren: logo options

Concept only. Chunky flanged pipework, drawn from scratch. Same outlined wordmark as before. Recommended: B.

A. Pipe ampersand above the wordmark

The "&" built as one continuous run of pipe, with collars, an amber flange at the open end and a drip.

Icon
32px
One colour
On mint

Honest take: bold and instantly pipework, and the two counters accidentally read as drops. The mark works alone at 32px. Weakness: with an "&" in the wordmark as well, you get two ampersands stacked.

B. Pipe ampersand inside the wordmark (recommended)

The same pipe ampersand takes the place of the "&" in "pell & wren". Nothing else in the type changes.

Icon
32px
One colour
On mint

Honest take: the clever one. The name and the trade are one object, there is no extra mark to place, and the header version is just this on one line. Weakness: it changes the "&" glyph, so the type is not 100% as before. It reads as a wordmark first, so the icon-only version is the pipe & alone.

C. Chunky pipe P

A flanged pipe run that bends into a P, with a union collar and a drop in the eye.

Icon
32px
One colour
On mint

Honest take: the safe one. A clear P, clearly pipe, and it echoes the earlier version most closely. But it is the least surprising and the P above "pell" repeats the initial.
